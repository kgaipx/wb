1项目背景与建设目标

竞品分析已验证：公考培训是体量大、需求旺、但 AI 渗透极浅、头部份额流失的赛道，存在清晰的产品空白。本节把行业事实转化为我们的建设目标。

1.1 行业背景（来自竞品报告）

  • 需求旺盛：2026 年国考报名 371.8 万人，报录比约 74:1，省考、事业单位、选调生等叠加，备考是长周期、高频、强焦虑的刚需。
  • 头部松动：公考 CR3（粉笔 / 华图 / 中公）市占率从巅峰 38% 回落至 19.2%（2024），用户正在外流，新进入者有机会。
  • AI 刚起步：标杆粉笔 2025 年 AI 相关收入仅占总收入 1.4%，直竞把 AI 当作"低价大班课的附赠"，尚未形成真正的个性化教学闭环。
  • 信任洼地：直竞最大品牌短板在"内容准确性 + 退费信任"——中公退费投诉 11.5 万条、华图"14 天不退 / 倒欠机构"、教材答案错误等，行业信任度极低。

1.2 竞争缺口（我们切入的依据）

通用 AI 工具的空白： Notion / Coda / ClickUp / Monday / Linear 在"垂直教学"上结构性为零——没有考试领域内容、没有学情闭环、AI 另收费。我们不需要和它们拼功能广度。
直竞的洼地： 直竞有内容但"AI 浅、教学不个性化、信任崩"。我们用 AI-native 的私教体验 + 透明信任型产品，正面击穿这两点。

1.3 建设目标

维度目标量化锚点
产品目标上线"AI 私教 + 公考内容测评 + 离线轻量 + 透明信任"的一体化学习平台MVP 覆盖行测/申论核心模块
体验目标做到"更懂短板、内容可信、花钱无忧、陪你上岸"的私教体验移动端 7 日留存 ≥ 行业 Top3
商业目标以学生友好的透明定价跑通付费转化，建立信任壁垒付费转化率、LTV/CAC 健康
阶段目标按 P0→P1→P2 推进，每阶段有明确可测信号，快速验证 PMF见第六章路线图

AI-native 的公考私教： 以"千人千面的教学闭环 + 可信内容 + 透明退费"为核心，不做又一个通用 AI 工具，也不做又一个卖课大班。

4功能模块规划

以下模块严格对应报告 5 个差异化方向。每个模块标注优先级（P0/P1/P2）与 MVP 范围，确保"先验证核心价值，再铺规模"。

4.1 学员中心与学习主页（基础，P0）

  • 注册 / 登录 / 微信绑定；学员档案（报考类别、目标岗位、基础测评）
  • 学习主页：今日任务、能力雷达图入口、薄弱点提醒、学习日历
  • 学情看板：刷题量、正确率趋势、各模块掌握度（能力图谱雏形）

4.2 AI 私教闭环（方向1 · P0）— 差异化核心

  • 逐题讲解： 错题/难题一键 AI 讲解（考点、思路、易错点、同类题推荐）
  • 短板诊断： 基于答题数据构建个人能力图谱（知识点 × 掌握度）
  • 自适应推送： 按记忆曲线（SM-2 类算法）自动推送复习与针对性练习
  • 答疑助手： 基于 RAG 的公考知识问答（政策、流程、考点）
  • MVP 范围：错题讲解 + 能力图谱 v1 + 基础自适应推送（报告验证信号：错题复错率下降）

4.3 公考垂直内容 + 测评一体化（方向2 · P0）

  • 结构化题库： 行测（言语/数量/判断/资料）、申论、公基；知识点标签 + 难度 + 年份
  • 历年真题 & 时政库： 国考/省考真题 + 实时时政（对接 5.5 时效管道）
  • 在线模考： 限时模考 + 自动判分 + 排名
  • 申论 AI 批改（单点 MVP）： 多维评分（立意/结构/论证/语言）+ 范文对比 + 修改建议（验证信号：人 AI 评分一致性 ≥0.8）
  • 提分报告： 模考后生成可分享的薄弱点与提分路径

4.4 离线优先 + 极简轻量（方向3 · P1）

  • PWA 离线缓存： Service Worker 缓存题库包与学习进度，IndexedDB 本地存储
  • 弱网同步： 答题/进度离线记录，网络恢复后增量同步
  • 移动刷题体验： 流畅切换、键盘/手势操作、零白屏（学 Linear 的"克制"）
  • MVP 范围：题库页离线缓存 demo + 通勤族实测（验证信号：移动端 7 日留存提升）

4.5 学生友好透明定价（方向4 · P1）

  • 简洁会员结构： 基础免费 + 进阶会员，AI 私教 / 批改等核心能力全部含在会员内，不学 ClickUp 的 AI 附加费、Monday 的积分黑盒
  • 学生认证折扣： 学信网/在校认证 → 专属价
  • 定价 A/B： "全含 AI" vs "AI 另购"对照，监测转化率与价格疑虑（验证信号：付费转化率、价格流失下降）

4.6 信任优先型产品（方向5 · P0）

  • 无忧退费： "7 天无理由 + 未过退部分款"的透明规则引擎，自动可查，直面中公退费灾难
  • 内容可信： 时政实时更新 + 答案 AI 校验 + 人工复核流程，抽检准确率对标（避免华图教材错误）
  • 信任可视化： 退费进度可追踪、内容更新时间可见、评分依据可解释
  • 验证信号：信任 NPS、退费纠纷率下降

5关键技术方案

本章给出差异化能力的工程实现要点，重点在 AI 私教、申论批改、自适应引擎、离线、内容可信与计费退费。

5.1 AI 私教 Agent 架构

  • 上下文=学情： 借鉴 Notion"上下文主权"，但把上下文换成"学员画像（错题、掌握度、目标岗位）"，形成教学反馈闭环而非文档问答。
  • RAG 知识层： 公考法规/时政/真题/考点入库向量检索，约束大模型幻觉、保证答案有出处。
  • Agent 编排： 讲题 / 诊断 / 答疑 / 推题 四类子能力，由编排层按场景路由；统一输出结构化（含考点、易错点、推荐题 ID）。
  • 可观测： 每次讲解打点（是否被采纳、是否追问），反哺诊断与推送。

5.2 申论智能批改引擎

  • 评分框架： 按官方评分要素拆维度（立意准确 / 结构完整 / 论证充分 / 语言规范 / 对策可行），每维配 rubric 与权重。
  • 两阶段： LLM 初评（多视角采分点抽取）→ 校准层（与历史样卷/人工标注对齐，抑制打分漂移）。
  • 验收门槛： 50 份真实答卷人工 vs AI 评分相关系数 ≥0.8 方可上线（报告验证建议）。
  • 可解释： 不仅给分，给"失分点 + 修改建议 + 范文片段"，降低用户对黑盒的抵触。

5.3 自适应学习引擎

  • 能力诊断： 基于 Item Response Theory（IRT）或知识追踪（BKT/Deep Knowledge Tracing）估算各知识点掌握度。
  • 推送策略： 结合 SM-2 记忆曲线与掌握度，生成"复习旧知 + 攻克薄弱 + 适度挑战"的日计划。
  • 闭环： 推送 → 作答 → 重新诊断 → 再推送，形成报告强调的"教学 Agent 闭环"。

5.4 离线 PWA 方案

  • Service Worker（Workbox）预缓存题库包（按考点分包）、讲解资源；答题与进度写入 IndexedDB。
  • 增量同步：网络恢复后按"最后写入胜出 + 冲突检测"同步，保证多端一致。
  • 性能基线：首屏 <1.5s、题库切换无白屏、弱网（3G）可用。

5.5 内容可信与时效管道

  • 时政时效： 定时抓取权威来源（政府网/新华社等）+ AI 摘要 + 人工复核后入库，标注更新时间。
  • 答案校验： 新题/更新题经"AI 交叉验证 + 教研人工复核"双签，错题进入更正流并通知受影响用户。
  • 合规留痕： 内容版本与复核记录可追溯，应对版权与准确性争议。

5.6 计费与退费系统

  • 透明会员： 价格页明示"AI 全含"，无隐藏积分/席位叠加。
  • 退费规则引擎： 把"7 天无理由 / 未过退部分款"固化为可配置规则，进度可查、到账时限明确（治理中公式套路）。
  • 学生认证： 对接学信网/在校证明，发放折扣权益。

8研发管理与工程流程

  • 敏捷双周迭代： 2 周一个 Sprint，MVP 阶段约 3 个 Sprint 完成阶段1。
  • 需求流： Epic（方向）→ Story（功能点）→ Task；需求评审冻结 MVP 范围，避免范围蔓延。
  • 开发流： 分支开发 → PR + Code Review → CI 自动化测试 → 预发 → 灰度发布（先小流量验证 AI 能力）。
  • 环境： 开发 / 测试 / 预发 / 生产 四环境隔离；AI 能力设"影子模式"先观测后放量。
  • 指标驱动： 每个 Sprint 复盘对照第十二章 KPI，未达信号则下个 Sprint 优先补。

10数据安全与合规

  • 个人信息保护（PIPL）： 学员实名/学习数据最小化收集、加密存储、明确授权；提供注销与数据导出。
  • 内容版权： 题库/真题/时政通过授权或原创生产，建立版权台账；引用政策注明来源，规避侵权。
  • 宣传合规： "未过退部分款""AI 批改"等承诺须真实可履行，避免《广告法》绝对化用语与虚假宣传（直竞信任崩的前车之鉴）。
  • AI 合规： 生成内容标注"AI 辅助"，关键结论（如法律/政策）提供溯源，限制未成年人不适内容。
  • 支付与资金： 退费规则透明、到账时限明确，资金流合规，避免"协议班"式预收款风险。

12验收标准与成功指标

验收以"阶段信号 + 北极星"双轨。阶段信号直接取自报告第 6/7 章验证建议，确保方案与竞品分析闭环。

12.1 北极星指标

12.3 发布验收清单（阶段门禁）
