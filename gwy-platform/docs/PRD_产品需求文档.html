一、产品概述

1.1 定位与一句话价值

定位（方案 c2 定位声明）： 不做"又一个通用工具"，也不做"又一个卖课大班"，做 AI-native 的公考私教——更懂你短板、内容可信、花钱无忧、陪你上岸。

一句话价值： 用 AI 私教替代"低价大班课的附赠"，把备考从"刷不完的题"变成"精准补你短板的陪练"。

1.2 目标用户

  • 核心： 备考公务员/事业编的应届与在职考生（国考、省考、选调）。
  • 强需求画像： 自驱但缺乏个性化指导、预算敏感、对"内容是否靠谱/退费是否坑"高度敏感。

1.3 非目标（明确不做什么）

  • 不做通用文档/项目管理工具（避开 Notion/Coda 等参照系战场）。
  • MVP 阶段不做全渠道 App 矩阵（先 H5/PWA + 小程序）。
  • 不承诺"保过"等违反《广告法》的绝对化用语（方案 c10）。

五、MVP 范围（P0 冻结）

范围纪律（方案 c11 范围蔓延风险 → 应对）： MVP 仅做 P0 三大单点（方向1 私教闭环、方向2 申论批改、方向5 信任保障）+ 基础（学员中心、题库、质量合规）。P1（离线、定价）进入公测阶段，P2 规模化。
  • 必须包含： 学员中心(2.1)、基础题库(2.2)、AI私教(3.1)、自适应(3.2)、申论批改(4.1)、模考(4.2)、退费引擎(5.1)、内容校验(5.2)、质量合规(8.1)。
  • 明确推迟： 离线 PWA(6.1)、会员定价 A/B(7.1)、社群/推荐、全渠道 App。

六、非功能需求

  • 离线优先（方向3）： 题库页支持 PWA 离线刷题（WBS 6.1，公测阶段）。
  • 性能： AI 讲解首响 < 3s（流式输出）；核心接口 P95 < 300ms。
  • 安全合规（方案 c10）： PIPL 最小化收集 + 加密 + 可注销导出；生成内容标注"AI 辅助"；内容版权台账。
  • 可访问性： 移动端为主，适配 iOS/Android 主流机型。

七、关键用户流程（初稿）

  1. 注册/登录： 手机+验证码（JWT），学员中心初始化学情档案。
  2. 诊断： 首次测评 → 自适应引擎(3.2)生成能力图谱与弱项。
  3. 学习： AI 私教(3.1)逐题讲解 + RAG 知识支撑；错题进诊断闭环。
  4. 测评： 在线模考(4.2) → 申论 AI 批改(4.1) → 提分报告。
  5. 付费/保障： 透明定价(7.1) → 无忧退费(5.1)进度可查。
