▶新页面 / 功能通用走查流程

  1. 列维度：对照上文 4 大类 14 项，圈出本页涉及的项（如列表页必查 B1/B4/C1；表单页必查 C3/D4/A1）。
  2. 三断点截图：移动 390×844、平板 820×1180、桌面 1280×800 各截一帧，肉眼核对破版 / 遮挡 / 截断。
  3. 对比度复算：取「文字色 / 有效背景色」（注意半透明遮罩、渐变卡），普通 ≥4.5:1、大文本 ≥3:1；暗色主题单独跑。
  4. 键盘走查：Tab 顺序是否合理？有无 skip-link？模态/抽屉能否 Tab 循环且 Esc 关闭、关闭归还焦点？
  5. 三态走查：制造空数据（清 localStorage）→ 看 EmptyState；拦截接口 5xx → 看 ErrorState + 重试；loading 期间有骨架。
  6. 写操作走查：拦截写接口失败 → 确认有 toast/err 且乐观更新已回滚，绝无静默吞错。
  7. 表单走查：失焦即显内联错误 + 红框 + aria-invalid；改对即清；提交拦截非法值。
  8. 动效走查：开启系统「减少动态效果」后，转场/循环动画应全部禁用或降级。
